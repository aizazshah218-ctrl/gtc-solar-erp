# GTC Solar System ERP — Version 1

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

Open the URL shown by Streamlit.

### First login
- Username: `admin`
- Password: `admin123`

Change the default password before production use.

## Included
- Login / user roles
- Dashboard
- Customers & suppliers
- Product inventory and stock movement
- Sales and invoice register
- Purchases and purchase register
- Gate passes
- Expenses
- Ledger
- Reports and charts
- CSV exports

## Important
This is a Version 1 prototype for operational testing. Before production deployment, add PostgreSQL, HTTPS, stronger authentication, backups, audit logs, edit/delete controls, invoice/gate-pass PDF templates, tax configuration, and multi-user concurrency controls.
